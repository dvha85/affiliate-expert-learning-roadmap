# Learner path — Mission-based curriculum

Đây là đường học hiện hành cho người mới. Không dùng số lesson legacy trong `lessons/` để xác định thứ tự học.

## Bắt đầu

1. `BOOT.1` nếu chưa từng chạy/test Bot. Learner hiện tại đã có credit bài này từ pilot cũ.
2. `M00.1` → `M00.2` → `M00.3`.
3. Hoàn thành artifact/evidence của M00 trước khi sang M01.

## Quy tắc học

```text
TRY
→ OBSERVE GAP
→ PULL 1–3 SMALL KNOWLEDGE CARDS
→ BUILD / APPLY
→ TEST FAILURE CASE
→ SAVE EVIDENCE
→ EXPLAIN LIMITS
→ NEXT MEASUREMENT
```

Mỗi card phải trả lời một câu hỏi cụ thể phục vụ Mission hiện tại; không đọc theory chỉ để hoàn thành checklist.

## Mission sequence

`O00 → M00 → M01 → M02 → M03 → M04 → M05 → M06 → M07 → M08 → M09 → M10 → M11`

Authority tăng dần; learner không được dùng capability của Mission sau để vượt gate của Mission trước.
