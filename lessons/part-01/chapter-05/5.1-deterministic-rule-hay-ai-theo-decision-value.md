# Bài 5.1 — Chọn quy tắc tất định (`deterministic rule`) hay AI theo giá trị quyết định

> **Track:** `core` · **Mission:** `M02` · **Thời lượng dự kiến:** 65 phút
>
> Chỉ kéo bài này sau khi đã làm M02 Checkpoint 1: freeze human labels + deterministic baseline trước AI.

## 1. Trigger — câu hỏi không phải “có AI không?”

Bạn đã có Bot v0.2 với history đáng tin và deterministic baseline. Câu hỏi mới là:

```text
Có nên gọi AI cho case này không?
```

Nếu deterministic code đã đủ, gọi AI chỉ thêm cost, latency và một trust boundary mới.

Nếu evidence thiếu một phép đo thật, AI cũng không thể biến `unknown` thành `fact`.

Nếu câu hỏi là unstructured interpretation có thể giúp giảm uncertainty, AI có thể đáng gọi — nhưng ở M02 vẫn chỉ là **AI Advisor (AI tư vấn)**.

Mental model:

```text
Evidence đáng tin
      ↓
Deterministic baseline FIRST
      ↓
Baseline đủ cho câu hỏi này?
  ├─ yes → SKIP_AI
  └─ no
       ↓
Có câu hỏi unstructured cụ thể?
  ├─ no → GET_MORE_DATA / deterministic path
  └─ yes
       ↓
Expected information value > cost/risk?
  ├─ no → SKIP_AI
  └─ yes → CALL_AI
```

---

## 2. Ranh giới bắt buộc: AI Advisor (A1) ≠ Agent Runtime

Ở M02:

```text
AI Advisor (A1)
= model call có kiểm soát
+ input evidence rõ
+ output schema rõ
+ grounding/fallback
+ human-visible analysis
```

Nó **không phải Agent runtime**.

M02 không có:

```text
tool use
autonomous loop
shell / arbitrary command
persistent memory mutation
internal write authority
external write authority
Action execution
```

Agent dùng tool chỉ xuất hiện ở Mission sau, với authority gate riêng. Việc repo đã chọn kiến trúc Hybrid Go + n8n + Agent **không phải lý do kéo Agent vào M02**.

Invariant:

```text
M02 Advisor
= analyze / recommend / abstain only
≠ tool user
≠ execution actor
```

## 3. Thử trước — audit attempt vừa làm

Mở eval subset đã freeze ở Checkpoint 1.

Với từng case, ghi:

```yaml
case_id:
deterministic_baseline:
baseline_limitation:
question_for_ai:
expected_information_value:
call_decision: CALL_AI | SKIP_AI
reason:
```

Ví dụ:

```text
Case A
Baseline: price × commission rate đã đủ để sort theo baseline hiện tại
Question for AI: không có câu hỏi unstructured cụ thể
Decision: SKIP_AI
```

```text
Case B
Baseline: source có seller text dài về feature/problem
Question for AI: trích candidate problem statements để human review
Decision: CALL_AI
```

Không dùng lý do:

```text
CALL_AI vì AI thông minh hơn
```

---

## 4. Ba loại gap phải phân biệt

### Gap A — tính toán tất định

Ví dụ:

```text
price × commission_rate
```

Không cần AI.

### Gap B — thiếu evidence thật

Ví dụ:

```text
CVR = unknown
refund rate = unknown
valid-order rate = unknown
```

AI không thể tạo measured value.

Behavior đúng thường là:

```text
GET_MORE_DATA
```

hoặc giữ `unknown`.

### Gap C — diễn giải dữ liệu phi cấu trúc

Ví dụ:

```text
source text dài
→ cần extract candidate claims
→ cần nhóm feature/problem được mô tả
```

Đây là nơi AI có thể tạo information utility nếu output đi qua grounding gate.

---

## 5. Khi nào ưu tiên deterministic rule?

Ưu tiên deterministic code khi:

- input structured rõ;
- rule testable/explainable;
- same input cần same output;
- task là arithmetic/filtering/validation/state transition;
- AI không thêm evidence mới;
- false positive có cost đáng kể.

Ví dụ:

```text
commission_per_order = price × commission_rate
```

không có lý do tốt để hỏi model.

---

## 6. Khi nào AI có thể đáng dùng?

AI có thể hữu ích cho:

- đọc text unstructured;
- candidate extraction;
- summarize evidence;
- tạo hypothesis;
- phát hiện ambiguity;
- đề xuất next measurement.

Nhưng output vẫn là:

```text
untrusted advisory
```

không phải market truth.

---

## 7. Giá trị quyết định khác “AI accuracy”

Một model có thể trả lời rất hay nhưng vẫn không đáng gọi.

Cân ít nhất:

```text
Information value
Cost
Latency
Risk
```

Ví dụ:

```text
AI chỉ tóm tắt 2 dòng text đã rất rõ
→ information gain thấp
→ SKIP_AI
```

Hoặc:

```text
AI có thể extract 8 candidate claims từ nhiều đoạn mô tả dài
→ giảm thời gian human review
→ CALL_AI có thể hợp lý
```

M02 không cần numeric ROI. Learner chỉ cần nói được:

> Nếu gọi AI, uncertainty nào tôi kỳ vọng nó giúp cấu trúc lại?

---

## 8. `SKIP_AI` là một kết quả tốt

Một Bot trưởng thành không đo “AI maturity” bằng số lần gọi model.

```text
Baseline đủ
→ SKIP_AI
→ capability không mất
→ cost giảm
→ latency giảm
→ trust surface nhỏ hơn
```

Do đó M02 PASS bắt buộc có ít nhất một `SKIP_AI` case hợp lý.

---

## 9. Apply — tạo quyết định gọi AI trước provider

Tạo behavior tương đương:

```text
DecideAdvisorInvocation(context)
→ CALL_AI | SKIP_AI
→ reason
```

Inputs có thể gồm:

- deterministic baseline state;
- missing evidence;
- unstructured question;
- budget/risk flag nhỏ.

Output phải inspectable.

Ví dụ:

```text
AI invocation: SKIP_AI
Reason: baseline đủ cho structured ranking; không có unstructured question
```

hoặc:

```text
AI invocation: CALL_AI
Reason: cần extract candidate claims để human review
```

---

## 10. Failure test — “có provider thì luôn gọi”

Implementation cố ý sai:

```text
if advisor != nil {
    always call advisor
}
```

Viết test cho case:

```text
baseline đủ + no unstructured question
```

Expected:

```text
SKIP_AI
provider call count = 0
```

---

## 11. Missing evidence không được giao cho AI đoán

Input:

```text
conversion_rate = unknown
```

Câu hỏi sai:

```text
AI hãy cho tôi một CVR hợp lý để ranking
```

Behavior đúng:

```text
CVR remains unknown
recommended state có thể vẫn GET_MORE_DATA
AI chỉ có thể gợi ý cách đo CVR
```

## 13. Checkpoint

1. Khi nào deterministic rule tốt hơn AI?
2. Missing measured evidence có phải lý do để AI bịa value không?
3. Vì sao `SKIP_AI` có thể là output tốt?
4. `CALL_AI` phải gắn với câu hỏi cụ thể nào?
5. AI Advisor M02 khác Agent runtime thế nào?

<details>
<summary><strong>Đáp án / rubric</strong></summary>

- Deterministic ưu tiên cho structured, testable, reproducible logic.
- Missing evidence vẫn là unknown; AI không biến nó thành measured fact.
- `SKIP_AI` giảm cost/latency/risk khi information gain thấp.
- `CALL_AI` cần unstructured analysis question + expected information value rõ.
- M02 Advisor không có tool/autonomous loop/write/action authority.
- Blocking misconception: “càng gọi AI nhiều Bot càng thông minh”.

</details>
