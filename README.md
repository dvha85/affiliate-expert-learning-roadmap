# Affiliate Expert Learning Roadmap

Roadmap thực hành để phát triển đồng thời ba năng lực:

**Affiliate Expert + Affiliate Bot Engineer = Affiliate Intelligence Expert**

Roadmap được chuẩn hóa từ ba tài liệu nguồn v2026.08 và thiết kế cho nhịp **9 giờ/tuần**, review cố định **12:00 Chủ nhật**.

## Bắt đầu ở đây

1. Mở [ROADMAP.md](ROADMAP.md) để xem toàn bộ 23 phần.
2. Vào file của phần hiện tại và học theo đúng thứ tự bài.
3. Chỉ đổi `[ ]` thành `[x]` sau khi đạt đủ [5 tiêu chí PASS](docs/PASS-CRITERIA.md).
4. Dùng [mẫu ghi chú bài học](templates/LESSON-NOTES.md) để lưu evidence.
5. Cập nhật [PROGRESS.md](PROGRESS.md) trong buổi review Chủ nhật.

## Quy mô chương trình

- **23 phần**
- **89 chương**
- **671 bài học có thể tick**
- **14 project chính**, kèm Lab và Pass Gate
- Lộ trình chính **12 tháng**, sau đó Scale → Research → SaaS → Mastery

## Nguyên tắc vận hành

```text
LEARN → EXPLAIN → APPLY → TEST → PASS
```

- 30% Learn, 70% Do.
- Data > Opinion.
- Expected Value > Commission Rate.
- Không automate thứ chưa hiểu bằng tay.
- Bot hỗ trợ quyết định; không spam, tạo tương tác giả hoặc né policy.
