# Build-First Learning Model v2

Sequence authority: [CURRICULUM.md](../CURRICULUM.md). Build-first means an
attempt creates a concrete gap before theory, not that the learner writes code
before seeing a human market context.

## V2 execution model

```text
O00 synthetic walkthrough (E0, non-PASS)
→ M00 safe human-only market loop (E1→E2)
→ M01 first outcome snapshot ∥ M02 smallest deterministic Bot
→ M03 trustworthy history & measurement
→ M04 grounded AI advisor
→ M05 reviewed improvement
→ M06–M11 governed production
```

M00 is manual by design. The learner may use forms, a template or a local file
as an auditable artifact; no Go/tooling requirement may block first market
contact. M02 chooses the smallest deterministic profile justified by the
evidence. The v1 Go starter is a reference/knowledge asset, not a hidden v2
entry prerequisite.

## Mission contract

Each authored v2 Mission must state:

1. the smallest observable attempt and its failure path;
2. the evidence level and what remains pending;
3. authority ceiling and prohibited actions;
4. at most three immediate knowledge pulls;
5. starter/eval/verification/pilot readiness separately from authoring status;
6. actual-time and blocker fields for recalibration.

M01/M02 are parallel only after M00; M03 must reconcile both outputs. A learner
may continue permitted engineering while waiting for an outcome, but cannot
declare reality verified from synthetic data.
