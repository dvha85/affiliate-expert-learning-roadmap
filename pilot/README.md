# PR9 pilot kit — do not fabricate results

The pilot starts only after a human recruits 5–10 consenting beginners. There
is no hidden telemetry: use the redacted session and aggregate templates, keep
identifying/raw material in ignored `pilot/raw/`, and commit an aggregate only
after review.

Track focused time separately from waiting time. `not_started` is the only
truthful status until real sessions exist.
