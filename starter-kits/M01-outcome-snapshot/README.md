# M01 starter — Outcome snapshot

Copy `M01-OUTCOME-SNAPSHOT.md` vào `artifacts/local/` hoặc private evidence
location trước khi điền. File này là manual/read-only scaffold; không có
credential, tracking secret, customer data hay analytics export mẫu.

Chạy structural check:

```bash
python scripts/validate_m01_outcome_snapshot_pack.py --snapshot artifacts/local/m01-outcome-snapshot.md
```

`evals/M01-outcome-snapshot/` chỉ là fixture cho evaluator, không phải E3.
