# M02 checkpoints — attempt before knowledge

## Checkpoint 1 — expected safe state

Run valid/missing/zero fixtures. Write your predicted state and weakest
assumption before opening the rule card.

## Checkpoint 2 — intentional failure

Choose duplicate, identity-conflict, mixed-currency or deterministic-tie.
Add a failing assertion or manual expected-output note, then verify it.

## Checkpoint 3 — Decision Context Card

Fill `DECISION-CONTEXT-CARD.md` with a permitted evidence reference. If it is
synthetic, call it E0; do not relabel it as a public observation.
